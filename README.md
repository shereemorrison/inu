# INU (犬)

Futuristic dog brand portfolio site — immersive scroll, WebGL, and bold typography.

## Stack

- **Vite** + **React** + **TypeScript**
- **Tailwind CSS** v4
- **React Three Fiber** + **Drei** + **Three.js**
- **GSAP** — scroll choreography & motion
- **Lenis** — smooth scroll

## Development

```bash
npm install
npm run dev
```

```bash
npm run build   # production build
npm run preview # preview production build
```

## Project structure

```
src/
  components/   # UI primitives & chrome
  sections/     # Page sections (hero, story, etc.)
  three/        # R3F scenes & models
  hooks/        # Lenis, scroll, interaction
  lib/          # Utilities
  styles/       # Design tokens
```
